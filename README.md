# MSC — King Style (v1.3)

تطبيق Flutter لأجهزة أندرويد ذات شريحتين:
- تخصيص شريحة واحدة للإنترنت فقط
- رفض أو كتم المكالمات الواردة على تلك الشريحة
- أرقام مسموحة + جهات الاتصال + سجل المكالمات المحجوبة

## الجديد في v1.3
- **تشغيل/إيقاف الحظر** مؤقتاً دون إلغاء تخصيص الشريحة
- **السماح لجهات الاتصال** (اختياري، يطلب صلاحية جهات الاتصال)
- **إشعار صامت** عند كل مكالمة محجوبة (اختياري)
- **حالة كل شريحة**: البيانات مفعّلة/مطفأة، شريحة البيانات الافتراضية، التجوال
- **إحصائيات**: عدد المحجوب، عدد الأرقام المسموحة، حالة الحماية
- **إضافة رقم من السجل** للمسموحة بضغطة واحدة
- دعم **الأرقام العربية/الفارسية** في المطابقة، ومنع تكرار الأرقام
- تحسين اكتشاف الشريحة في خدمة الحظر، وأي خطأ يسمح للمكالمة بالمرور (أمان)
- تأكيد قبل مسح السجل، وحدّ السجل 100 مكالمة
- معالجة رفض الصلاحية نهائياً (زر فتح إعدادات التطبيق) ومنع حلقات إعادة الطلب
- ضغط للتخطي في شاشة الدخول
- تقسيم الكود إلى ملفات: `theme` / `splash_gate` / `home_page` / `sim_channel`
- تحديثات توافق مع Flutter الحديث (`withValues`, `CardThemeData`, `permission_handler 12`)

## التشغيل
1. `flutter create --org com.example --project-name sim_data_app --platforms android sim_data_app`
2. انسخ محتويات هذا المجلد فوق المشروع الجديد (استبدل `pubspec.yaml` و `lib/` و `android/app/src/main/` و مجلد `assets/`)
3. في `android/app/build.gradle(.kts)` اجعل: `minSdk = 29`
4. `flutter pub get && flutter run`
   (على جهاز حقيقي بشريحتين — لا يعمل على المحاكي)

## ملاحظات
- يحتاج صلاحية الهاتف + دور «تصفية المكالمات» (Call Screening)
- تبديل شريحة البيانات يتم يدوياً من إعدادات النظام (أندرويد لا يسمح للتطبيقات بذلك)
- بعض الأجهزة (Xiaomi / Huawei / Oppo) تحتاج السماح للتطبيق بالعمل في الخلفية وتعطيل توفير البطارية
- لم أستطع تشغيل `flutter analyze` هنا؛ جرّب `flutter analyze` عندك وأخبرني بأي خطأ يظهر
